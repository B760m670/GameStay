# LANTERNFALL — «Хранители Мглы»

Диздок (Game Design Document), версия 0.1 — прототип.

## 1. Концепция в одном абзаце

Стратегия о постройке и защите поселения + асинхронные атаки (жанр Clash of Clans),
но **главный ресурс и главное оружие — свет**. Мир затоплен Мглой. Строить можно только
в круге света своего Фонаря и Светочей. В бою оборона работает только пока на неё падает
свет, а войска можно высаживать только во тьме. Каждая атака — это не «снести всё», а
«погасить базу по частям»: сбил Светоч — сектор погрузился во тьму, башни в нём замолчали,
а твои войска могут высаживаться глубже.

## 2. Столпы дизайна

1. **Свет = территория.** Радиус света задаёт, где можно строить. Рост базы — это
   буквально «раздвигание тьмы» Светочами.
2. **Свет = энергия обороны.** Оборонительная постройка, на центр которой не падает свет,
   не стреляет. Расстановка Светочей — главное решение при планировке базы:
   один Светоч на всё — дёшево, но уязвимо; дублирующее покрытие — надёжно, но дорого.
3. **Тьма = союзник атакующего.** Высадка только на неосвещённые клетки. Тенекрады
   невидимы во тьме. Заклинание «Затмение» временно гасит участок базы.
4. **Нет доната.** Премиальная валюта (Осколки) добывается только игрой: ночные обороны,
   кампания. Ускорения есть, но заработаны.
5. **Короткие сессии.** Бой — 3 минуты, ночь — 90 секунд.

## 3. Отличия от Clash of Clans

| CoC | Lanternfall |
|---|---|
| Строишь где угодно на карте | Строишь только в свете (Фонарь + Светочи) |
| Оборона работает всегда | Оборона работает только в свете |
| Высадка по краю карты | Высадка в любой тьме — зона высадки меняется по ходу боя |
| Защита только от игроков | Каждую «ночь» базу штурмует Мгла (PvE-оборона, ты смотришь бой своей базы) |
| Заклинания-баффы | «Затмение» — тактическое отключение света |
| Гемы за деньги | Осколки — только за игру |

## 4. Ресурсы

- **Руда** — стройка обороны, стен, Фонаря, Светочей, Эфирных колодцев.
- **Эфир** — экономика, армия, тренировка войск. (Лор: Эфир — дистиллированная память.)
- **Осколки** — ускорение, хижины строителей. Добываются за ночи и кампанию.

## 5. Постройки

| Постройка | Роль |
|---|---|
| Фонарь (4×4) | Ратуша. Уровень Фонаря открывает всё остальное. Источник света. |
| Светоч (2×2) | Расширяет свет. Главная цель атакующих Тенекрадов. |
| Рудная шахта / Эфирный колодец | Добыча |
| Хранилища | Вместимость ресурсов |
| Казарма | Тренировка войск, уровень открывает новые войска |
| Лагерь | Вместимость армии |
| Хижина строителя | +1 строитель |
| Арбалет | Одиночная цель, земля+воздух, средняя дальность |
| Жаровня | Сплэш на ближней дистанции, только земля |
| Катапульта | Дальний сплэш, мёртвая зона вблизи, только земля |
| Призма | Луч, урон растёт пока держит цель, земля+воздух |
| Стена | Задерживает наземные войска |

Правило уровней: уровень постройки не может превышать «возраст» Фонаря с момента её открытия.

## 6. Войска Хранителя

| Юнит | Особенность |
|---|---|
| Факельщик | Дешёвый ближний бой, любая цель |
| Стрелок | Дальний бой, хрупкий |
| Щитоносец | Танк, идёт к обороне |
| Подрывник | Ищет стены, взрывается |
| Тенекрад | Охотится на источники света (×3 урона по ним), невидим во тьме |
| Филин | Летающий, бьёт оборону, игнорирует стены |

## 7. Порождения Мглы (ночная оборона)

Морок (рой), Громила (танк по обороне), Светоед (охота на свет, невидим в тени), Призрак (воздух).
Сила ночи растёт с уровнем Фонаря и количеством пережитых ночей.
Пережил ночь (Фонарь цел) — Осколки и ресурсы. Фонарь пал — потеря 10% запасов.

## 8. Бой

- 3 минуты. Три звезды-искры: ≥50% разрушений; Фонарь уничтожен; 100%.
- Добыча начисляется пропорционально урону по хранилищам/шахтам/Фонарю.
- Высаженные войска расходуются.

## 9. История

**Завязка.** Триста лет назад Великий Маяк на вершине Аргентума держал Мглу за краем мира.
Однажды ночью Маяк раскололся. Осколки разлетелись по земле, и Мгла хлынула в долины.
Ты — Хранитель, нашедший тлеющий осколок. Разожги Фонарь, построй поселение, верни миру свет.
Но другие Хранители — Угасшие — тоже держат осколки и служат шёпоту Мглы.

**Поворот (глава 6).** В Библиотеке Тишины героиня узнаёт: Эфир — это дистиллированная память.
Великий Маяк горел, сжигая воспоминания людей. Мгла — это пепел забытого, который
хочет вернуться к своим владельцам.

**Финал (глава 12).** В Сердце Маяка Хранитель должен решить: снова разжечь Маяк
(свет и безопасность ценой памяти) или позволить Мгле вернуться (память ценой тьмы).
Выбор — задел на следующий сезон.

## 10. Технологии прототипа

- Чистый JavaScript (ES-модули), Canvas 2D, изометрия, без ассетов — вся графика процедурная.
- `src/core` — детерминированная логика без DOM (симуляция боя, деревня, генерация баз) — тестируется в Node.
- `src/client` — рендер, камера, интерфейс.
- Сохранение в localStorage, оффлайн-прогресс по таймстемпам.
