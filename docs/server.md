# Сервер Lanternfall

Онлайн-часть игры: аккаунты, облачные сохранения, PvP-набеги на базы реальных игроков, лиги, кланы, глобальный и клановый чат.

## Устройство

- **Go** (`server/`): HTTP API, WebSocket-чат, база SQLite (`modernc.org/sqlite`, без внешних сервисов).
- **Ядро игры на C++** подключено через cgo (`engine/src/capi`): сервер считает бои и итоги теми же правилами,
  что и телефон. Ядро собирается скриптом `server/build_core.sh`.
- **Проверка атак.** Клиент присылает не итог, а *запись боя* (условия + действия игрока по шагам). Сервер сверяет
  армию, уровни отрядов, заклинания, героя и seed с сохранением атакующего и выданным матчем, затем сам прогоняет
  бой детерминированной симуляцией. Звёзды, добычу и рейтинг считает сервер — подделать их нельзя.
- **Щит.** После налёта база защитника 10 минут не попадается в поиск.

## API (JSON, заголовок `Authorization: Bearer <token>`)

| Метод | Путь | Что делает |
|---|---|---|
| POST | `/v1/register` `{name}` | новый игрок: `{id, token, save}` |
| GET | `/v1/me` | профиль и сохранение (доведённое до текущего момента) |
| PUT | `/v1/save` `{save}` | облачное сохранение (рейтинг меняется только боями на сервере) |
| POST | `/v1/match` | соперник близкого рейтинга: `{match, seed, snapshot, defender}` |
| POST | `/v1/attack` `{match, replay}` | проверка и зачёт атаки: `{result, save, defender_rating}` |
| GET | `/v1/defenses` | журнал обороны (кто нападал, звёзды, потери) |
| GET | `/v1/leaderboard` | топ-50 по рейтингу |
| POST | `/v1/clans` `{name, description, min_rating}` | создать клан |
| GET | `/v1/clans?q=` | поиск кланов |
| GET | `/v1/clans/{id}` | клан и участники |
| POST | `/v1/clans/{id}/join`, `/v1/clans/leave` | вступить / выйти (лидерство переходит сильнейшему) |
| GET | `/v1/chat/{global\|clan}` | последние 50 сообщений |
| POST | `/v1/report` `{message}` | жалоба; 3 жалобы скрывают сообщение |
| GET | `/v1/ws?token=` | WebSocket чата: `{"type":"say","channel":"global"\|"clan","text":"..."}` |

Модерация чата: фильтр мата, не чаще сообщения в 1,5 с, до 200 символов, жалобы, временный мьют (`muted_until`).

## Запуск локально

```bash
server/build_core.sh
cd server && go test -race ./... && go run . -addr :8080 -db lanternfall.db
```

## Развёртывание

`docker build -f server/Dockerfile -t lanternfall-server .` из корня репозитория, затем запуск с томом `/data`
для базы. Подойдёт любой VPS с Docker. Доступы к хостингу хранятся только в настройках GitHub (Secrets),
не в репозитории и не в переписке.
